# Video Game Sales Dashboard

A Power BI dashboard built to analyze video game sales data across platforms, genres, and years.

## About

This dashboard shows global video game sales trends using an interactive Power BI report.

## Visuals Included

- Global sales trend over the years (line chart)
- Number of games released per year (line chart)
- Sales by platform (donut chart)
- Sales by genre (bar chart)
- Summary cards (EU sales, genre info)
- Platform slicer for filtering

## Dataset

Video game sales dataset (Name, Platform, Year, Genre, Global Sales, EU Sales).

## How to Open

1. Download `videogame.pbix`
2. Open it in Power BI Desktop
3. Use the slicer to filter by platform

## Tools Used

- Power BI Desktop
- DAX
