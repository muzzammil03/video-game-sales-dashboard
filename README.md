# 🎮 Video Game Sales Dashboard

An interactive **Power BI** dashboard that explores global video game sales across **platforms, genres, and release years**.

![Dashboard Preview](images/dashboard.png)

---

## 📌 Overview

This project turns a raw video game sales dataset into a single-page, interactive report that answers questions like:

- How have global video game sales changed over the years?
- How many games were released each year?
- Which platforms and genres generate the most sales?
- How do sales look for a specific platform?

---

## 📊 Dashboard Visuals

| Visual | Chart Type | What it shows |
| --- | --- | --- |
| Global Sales by Year | Line chart | Trend of total global sales over time |
| Games Released by Year | Line chart | Number of games released each year |
| Sales by Platform | Donut chart | Share of global sales for each platform |
| Sales by Genre | Bar chart | Global sales compared across genres |
| EU Sales | Card | Total sales in the European region |
| Platform Slicer | Slicer | Filters the entire dashboard by platform |

## 🗃️ Dataset

The dataset contains video game sales records with these fields:

| Column | Description |
| --- | --- |
| `Name` | Name of the game |
| `Platform` | Platform the game was released on |
| `Year` | Release year |
| `Genre` | Game genre |
| `Global_Sales` | Worldwide sales |
| `EU_Sales` | Sales in Europe |

## 🚀 How to Open

1. Download or clone this repository:
```bash
   git clone https://github.com/muzzammil03/video-game-sales-dashboard.git
```
2. Install [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free, Windows only)
3. Open `video-game-sales-dashboard.pbix` in Power BI Desktop
4. Use the **Platform slicer** to filter all visuals

> 💡 Power BI Desktop is available only on Windows. Mac/Linux users can check the dashboard preview image above.
